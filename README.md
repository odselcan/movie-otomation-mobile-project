# 🎬 Cinema Automation Mobile

A cinema automation mobile application developed with React Native and Expo.

## Features

- 🎥 **Movie and TV Show Search** – Search for movies and TV shows using the TMDB API.
- 📍 **Nearby Cinemas** – Find nearby cinemas on Google Maps.
- ❤️ **Favorites and Watchlist** – Manage your favorite movies and watchlist.
- 📡 **Sensor Data** – Access GPS, battery, network, and accelerometer data.
- 📞 **Calling and SMS** – Call cinemas and send SMS messages.
- 🌍 **Multilingual Support** – Supports Turkish, English, and French (TR/EN/FR).
- 🔔 **Notifications** – Notification support.

## Technologies Used

- Expo SDK 57
- Expo Router
- React Native Maps
- TMDB API
- expo-sensors
- expo-location
- expo-battery
- expo-sms
- expo-contacts
